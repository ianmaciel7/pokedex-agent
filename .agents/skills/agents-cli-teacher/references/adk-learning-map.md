# ADK learning map

Use this reference when you need to compare local notes with current ADK
documentation, build a learning sequence, or decide whether a reference file
should be updated or created.

## Core idea

Start with the local skill or reference that already covers the topic. Then
check the official ADK site for the current page names and learning sequence.
Use both sources together before deciding what should change.

## What to compare

When reviewing a topic, check three things:

* whether the local reference already covers the concept;
* whether the official site uses a newer page name or structure;
* whether the gap is a small edit or a new reference file.

## Update vs create

Update an existing reference when:

* the topic is already covered;
* the new information only clarifies scope or ordering;
* the learning path changes but the concept stays the same.

Create a new reference when:

* the topic crosses into a different ADK area;
* the official docs introduce a distinct concept;
* the new material would make an existing reference too broad.

## Working rule

Prefer a short, reusable reference over a long repo-specific note. The goal is
to capture a stable pattern that can be reused in other projects with minimal
editing.

# Optimize

Use this reference when the conversation is about improving agents based on
evaluation results.

## Core idea

Optimization turns eval feedback into better prompts, settings, or strategies.

## Why it matters

It helps close the loop between measurement and improvement.

## Main idea

* Evaluate first.
* Optimize next.
* Re-evaluate after changes.

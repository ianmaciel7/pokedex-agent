# Skills

Use this reference when the conversation is about ADK skills and the
SkillToolset.

## Core idea

Skills are reusable capability packages that an agent can load from code or a
filesystem.

## Main topics

* SkillToolset
* loading skills from a directory
* skill registry
* targeted skill retrieval

## Why it matters

Skills help organize reusable instructions and tools without forcing them into
one giant prompt.

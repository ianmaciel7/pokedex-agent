# Agents

Use this reference when the conversation is about the main ADK agent family
and how the broad agent categories relate to each other.

## Core idea

The ADK site groups agents into simple agents, custom agents, workflow
agents, and routing-oriented patterns.

## Main buckets

* Simple agents
* Custom agents
* Workflow agents
* Routing
* Model-backed agents

## How to think about it

* Start with a simple agent when the task is small.
* Move to custom agents when you need custom control flow.
* Use workflow agents when order, looping, or parallelism matters.
* Use routing when one request should branch to different agent paths.

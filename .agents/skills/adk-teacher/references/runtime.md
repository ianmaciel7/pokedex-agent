# Runtime

Use this reference when the conversation is about the ADK runtime surface as a
whole.

## Core idea

The runtime is the execution layer that runs the agent, handles turn flow,
and connects to web, CLI, and live interactions.

## Main topics

* `Runner`
* `RunConfig`
* command-line runtime
* API server
* ambient agents
* resume and cancel
* event loop
* web interface

## Why it matters

It separates the agent definition from how the agent is executed and tested.

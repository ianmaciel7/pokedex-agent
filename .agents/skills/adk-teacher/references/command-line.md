# Command Line

Use this reference when the conversation is about running ADK agents from the
terminal with `adk run`.

## Core idea

The command-line runtime gives you a fast way to test and interact with an
agent from the terminal.

## Why it matters

It is useful for quick testing, scripted interactions, and CI-style checks.

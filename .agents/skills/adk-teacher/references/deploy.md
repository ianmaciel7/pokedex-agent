# Deploy

Use this reference when the conversation is about getting an ADK agent into a
runtime target such as Agent Runtime, Cloud Run, or GKE.

## Core idea

Deployment is about taking a built agent and making it available in a managed
environment.

## Main areas

* Agent Runtime deployment
* `agents-cli` deployment flows
* Cloud Run deployment
* GKE deployment

## Why it matters

It separates local development from the production operating model and helps
keep configuration and infrastructure reproducible.

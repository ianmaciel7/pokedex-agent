# Evaluate

Use this reference when the conversation is about measuring agent quality with
datasets, metrics, or grading.

## Core idea

Evaluation gives you a repeatable way to measure whether the agent behaves the
way you expect.

## Main pieces

* evaluation criteria
* user simulation
* environment simulation
* custom metrics

## Why it matters

It is the quality gate that helps catch regressions and compare changes
systematically.

# Callback Patterns

Use this reference when the conversation is about recommended ways to use
callbacks.

## Core idea

Callback patterns show how to use hooks for observation, validation, and
control without overcomplicating the agent.

## Why it matters

It helps keep lifecycle hooks small, reusable, and predictable.

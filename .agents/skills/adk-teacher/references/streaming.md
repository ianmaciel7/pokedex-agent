# Streaming

Use this reference when the conversation is about real-time interaction with
an ADK agent.

## Core idea

Streaming enables incremental output and live interactions, often using the
runtime's live execution path.

## Main topics

* streaming quickstarts
* live interaction
* low-latency updates
* multimodal streaming

## Why it matters

It is the right choice when partial results or live feedback improve the
experience.

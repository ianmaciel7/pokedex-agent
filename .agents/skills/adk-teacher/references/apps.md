# Apps

Use this reference when the conversation is about app-facing ADK surfaces,
especially UI-oriented integrations.

## Core idea

The apps area covers how agents connect to user-facing experiences and app
surfaces.

## Why it matters

It helps clarify the difference between the agent runtime and the interface a
user sees.

## Main themes

* UI-oriented integrations
* cross-device interaction surfaces
* app-level presentation of agent output

# Custom Tools Catalog

Use this reference when the conversation is about the custom tool family
beyond simple function tools.

## Core idea

ADK's custom tools area includes function tools, long-running tools, MCP
tools, and openAPI-style integrations.

## Main topics

* function tools
* long-running function tools
* agents as tools
* MCP tools
* openAPI tools
* authentication
* confirmation and performance guidance

## Why it matters

It helps choose the right tool style for the problem instead of forcing one
approach everywhere.

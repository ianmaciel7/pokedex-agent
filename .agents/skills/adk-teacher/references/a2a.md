# A2A

Use this reference when the conversation is about agent-to-agent
interoperability.

## Core idea

A2A is the protocol area for connecting ADK agents with other agents. It is
about collaboration between agents rather than just tool calls.

## Why it matters

It gives a standard way to expose, consume, and extend agent interactions
across systems.

## What to remember

* Use A2A when the task is agent-to-agent communication.
* Use ADK workflows when the coordination stays inside one application.
* Keep the boundary clear between local orchestration and external agent
  interoperability.

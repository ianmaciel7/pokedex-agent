# RunConfig

Use this reference when the conversation is about runtime behavior settings
such as streaming, live options, speech, or call limits.

## Core idea

`RunConfig` lets you adjust how the runner executes an agent without changing
the agent definition itself.

## What it controls

* streaming mode
* speech settings
* LLM call limits
* live agent options

## Why it matters

It is the runtime tuning layer for interaction behavior.

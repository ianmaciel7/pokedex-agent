# Events

Use this reference when the conversation is about execution events in ADK.

## Core idea

Events are the fundamental information units that flow through the runtime
while an agent is running.

## Why it matters

They help explain what happened during a turn, what state changed, and how
the runtime moved through the task.

## What to remember

* Events are part of the execution trace.
* They are not the same as session state or artifacts.
* They are useful for debugging and runtime inspection.

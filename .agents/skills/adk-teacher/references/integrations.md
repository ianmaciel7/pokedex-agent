# Integrations

Use this reference when the conversation is about the broader ADK integrations
catalog rather than a specific MCP connection.

## Core idea

ADK provides an integration surface for external capabilities such as search,
data systems, observability, and other connectors. The main question is which
integration pattern fits the task and environment.

## Why it matters

Integrations let an agent reuse existing services instead of rebuilding them
inside the application.

## Common themes

* external connector catalogs;
* built-in versus third-party integrations;
* security and credential handling;
* choosing the smallest capability that solves the problem.

## When to use it

Use this reference when the task is about the integration landscape in ADK,
not only MCP.

## Good pattern

1. Prefer built-in capabilities where they already solve the need.
2. Use an integration when the service already exists externally.
3. Keep the integration narrow and purpose-built.

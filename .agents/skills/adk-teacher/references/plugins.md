# Plugins

Use this reference when the conversation is about reusable hooks that extend
ADK behavior.

## Core idea

Plugins provide shared callback hooks and extension points for agent
behavior, especially around lifecycle events and guardrails.

## Why it matters

They let you centralize behavior that would otherwise be repeated across many
agents.

## What to remember

* Plugins complement callbacks.
* Use them for cross-cutting concerns.
* Keep the smallest extension that solves the problem.

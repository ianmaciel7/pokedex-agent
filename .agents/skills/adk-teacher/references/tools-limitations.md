# Tools Limitations

Use this reference when the conversation is about the limits and tradeoffs of
the ADK tools area.

## Core idea

The limitations page explains what the built-in tool surface can and cannot do
well, and where you may need another integration pattern.

## Why it matters

It helps you avoid assuming that every capability should be a built-in tool.

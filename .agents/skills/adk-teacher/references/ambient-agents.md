# Ambient Agents

Use this reference when the conversation is about autonomous agents that run
in response to events rather than direct user chat.

## Core idea

Ambient agents process events asynchronously and can work in the background
without a human waiting on every turn.

## Why it matters

It is the right pattern for event-driven or monitoring-style automation.

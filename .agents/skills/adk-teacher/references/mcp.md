# MCP

Use this reference when the conversation is about the Model Context Protocol
area in ADK.

## Core idea

MCP is the protocol layer for connecting agents to external tool servers.

## Why it matters

It gives a standard interface for integrating external capabilities without
building custom transport code.

## What to remember

* Use MCP when a tool server already exists.
* Use the MCP integration layer from the agent when you want discovery and
  reuse.
* Keep the server boundary and tool filtering explicit.
